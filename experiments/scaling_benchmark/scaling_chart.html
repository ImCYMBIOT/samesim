Wall-clock time vs. agent count

Same gossip experiment (50 fixed ticks, no early stopping), single run per point. The two lines aren't "two ways to run Simul8" — they isolate two different costs: the core engine's own scaling (Ring topology, O(n) to generate) versus the full pipeline including a topology generator plugin (Erdős–Rényi) that happens to be O(n²).

Ring — engine only local slope 1.0–1.1 throughout
Erdős–Rényi — + O(n²) topology gen slope 0.89 → 1.37
Single run per point (this benchmark measures raw compute cost, not stochastic behavior — see the topology validation study for seed-averaged statistics). Erdős–Rényi capped at n=30,000: at that scale its O(n²) topology generator already dominates total time, and following the same trend to n=100,000 would take on the order of 20+ minutes for that step alone.
